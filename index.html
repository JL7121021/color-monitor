    GUIDE v2.9.6 使用方法與功能指南

    Close with ✕ (top-right), press Esc, or click the dark backdrop outside this dialog.
    GitHub: JL7121021/color-monitor (★ Star)

    1. 開始監控畫面

    • 點擊右側控制面板的「開始分享監控畫面」按鈕。
    • 在瀏覽器彈出的視窗中，選擇要監控的分頁、視窗或整個螢幕（建議選擇狀態監控畫面所在的視窗）。

    2. 區域設定與對齊

    • 畫面中央會出現區域 1、2、3 的檢測框。
    • 移動位置：拖曳檢測框或取樣探針，或先聚焦再用方向鍵移動。區域模式可用 Shift + 方向鍵調整大小；精準取樣則是大步移動。
    • 拖曳十字準星放到想取樣的像素位置，畫面會顯示區域編號與十字中央的即時取樣顏色。
    • 縮放畫面：使用右上角 + / − 按鈕或滾輪縮放，放大後可拖曳背景平移。

    3. 參數調整與控制

    • 檢測模式：精準取樣（取 1px 單點）或區域平均色；切換時會自動重設基準值。
    • 靈敏度：顏色變動百分比超過門檻（預設 4%）時觸發警報。
    • 排程自動控制：設定每日開始與停止時間。瀏覽器要求點擊才能分享畫面，因此排程時間到時會提示你按下開始按鈕。

    4. 自動記憶功能 (LocalStorage)

    • 配色、印花、檢測模式、間隔、靈敏度、排程、各區域座標與開關狀態都會自動儲存，重新整理後還原。

    5. 外觀風格與已儲存外觀 (Style Kit)

    • 右上角可切換語言（EN/zh-HK）、⚙ 外觀面板，以及工具列上的 Day / Night 切換（套用所有風格）。
    • 可為目前外觀命名儲存、一鍵套用或刪除，並匯出 / 匯入 JSON 設定檔。
    • 外觀使用獨立的 LocalStorage 鍵，不會影響監控設定與區域座標。
    版本歷史

    v2.9.6最新

    • 預設改為英文與 Neumorphism 白天模式；語言切換顯示為 EN / zh-HK 並即時更新按鈕說明。
    • Day / Night 改為頁首按鈕（「Dark / Light」）；外觀面板移除重複的明暗切換。
    • 步驟指引可上一步／下一步，關閉後可從頁首重新開啟；GUIDE 視窗加入右上角關閉按鈕（✕）、可按 Esc 或點背景關閉。
    • 開始分享後，步驟 2 會一直顯示，直到使用者按「下一步」才進入步驟 3。
    • GUIDE 視窗提供關閉方式說明，並加入 GitHub 專案與 ★ Star 連結。

    v2.9.5

    • Neumorphism 改為參考網站的淺灰軟 UI：無硬邊框、同色表面、雙層明暗陰影。
    • 輸入框改為內凹軌道，按鈕與開關加入按壓內凹回饋；外觀面板新增適用所有風格的 Day / Night 明暗切換。
    • Terminal 改為真正的 CRT 終端機外觀；修正 Neumorphism 頁面底色與表面同色導致右側光影不明顯的問題。

    v2.9.4

    • 等到新的影像影格才取樣，修正第一次取得的顏色可能不正確。
    • 加入三步驟引導提示，清楚告知開始分享、放置探針與調整監控。
    • 移除 Glass 與 Liquid Glass 外觀；舊設定會自動回到原版。
    • 修正 Neumorphism 的邊界、陰影與警示列樣式不一致問題。

    v2.9.3

    • 修正中間「開始分享監控畫面」被影片層覆蓋而無法點擊。
    • 新增自我測試與長時間監控健康狀態（最後取樣、停頓偵測、心跳紀錄）。
    • 精準取樣改用獨立座標，可指到畫面四個角落。
    • 修正切換檢測模式時未重設基準造成的誤警報。
    • 外觀面板改為跟隨觸發鈕定位，並新增版本歷史。

    v2.9.2

    • 新增繁中／英文即時切換與液態玻璃等外觀風格。
    • 簡化介面並修正版面位移問題。
    • 十字準星改為固定大小，並加上即時取樣顏色標籤。
